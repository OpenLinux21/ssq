# 双色球 · 本地模拟器（SSQ Local Simulator）

一个使用 Go 编写的 Linux 命令行双色球彩票**本地随机模拟**程序。
支持手动选号与自动机选（最多 5 注）、基于 `/dev/random` 的无偏随机开奖、
逐球揭晓动画、按官方现行规则判定中奖等级并输出详细统计报告。

> **免责声明**：本程序是纯本地随机模拟器，**不连接福利彩票官方系统，
> 不读取、不伪造真实开奖号码，不能预测真实开奖**。浮动奖金（一、二等奖）
> 一律显示"待官方核定"，程序不编造具体金额。请理性购彩。

## 功能特性

- 欢迎界面：程序版本、随机源状态、随机算法、规则依据与免责声明
- 选号方式：手动录入 / 自动机选一注 / 机选补满，单次最多 **5 注**
  （每注 6 个红球 01-33 + 1 个蓝球 01-16，红球升序、两位数字显示）
- 手动输入严格校验：数量、取值范围、重复号码、输入格式，
  错误时给出具体原因并允许重新输入（支持空格、中英文逗号、顿号等分隔）
- 随机源：读取 Linux `/dev/random`（内核 CSPRNG），**不使用 math/rand**；
  读取处理短读与 `EINTR`；阻塞超时 10 秒自动回退 `/dev/urandom` 并如实提示
- 无偏随机：`Intn` 采用拒绝采样消除取模偏差；红球用部分 Fisher-Yates 抽样去重
- 开奖动画：号码**先一次性取数**，再逐球揭晓（动画不影响随机数据正确性）
- 中奖判定：一至六等奖 + 福运奖（依据现行官方规则，见下文）
- 统计报告：每注命中明细、单注奖金、总成本、固定奖金总额、浮动奖金注数、
  可确定净收益与最终收益说明
- 终端美化：标准 ANSI 颜色（红球红、蓝球蓝、中奖绿、提示黄/青），
  支持 `NO_COLOR` 与非终端环境自动去色；bash / Fish Shell 均可正常显示
- Ctrl+C 优雅退出（提示 → 关闭随机源 → 退出码 130），正确处理 EOF 与非法输入

## 环境要求

- Linux（优先适配 Fedora），Go ≥ 1.26
- 存在 `/dev/random` 与 `/dev/urandom` 设备

Fedora 安装 Go：

```bash
sudo dnf install golang
```

## 交互流程

1. 启动后显示欢迎界面（版本、随机源状态、规则依据、免责声明）
2. 菜单选号：`[1]` 手动 / `[2]` 机选一注 / `[3]` 机选补满 / `[4]` 清空 /
   `[5]` 确认投注 / `[0]` 退出
3. 确认页展示全部投注号码与成本：`y` 确认开奖 / `r` 重新选号 / `q` 退出
4. 摇奖动画逐球揭晓（红球 6 个 → 蓝球 1 个）
5. 输出对奖明细与统计汇总

## 关键设计说明

### 1. 随机源（internal/randx）

- **只使用 `/dev/random`**（内核 CSPRNG），全程序不引用 `math/rand`。
  通过 `Entropy` 接口抽象熵源，测试中注入确定性数据。
- **短读与 EINTR**：`readFull` 循环读满所需字节，`EINTR` 自动重试。
- **阻塞处理**：读取整体设 10 秒超时（后台 goroutine + `select` 实现）；
  超时后切换到 `/dev/urandom`（同为内核 CSPRNG）并重试一次，
  通过 `OnFallback` 回调在界面上如实提示；不做无限重试。
- **无偏算法**：`Intn(n)` 拒绝采样——仅接受落在 `[0, 2⁶⁴−rem)` 区间的值
  （`rem = 2⁶⁴ mod n`），该区间长度能被 `n` 整除，因此 `v % n` 均匀无偏；
  红球去重采用部分 Fisher-Yates 抽样，保证组合分布均匀。
- **资源管理**：设备文件在启动时打开、`Close()` 幂等；Ctrl+C 时立即关闭，
  阻塞中的读取会因文件关闭而立即返回，不悬挂进程。

### 2. 中奖规则与奖金（internal/lotto/prize.go）

依据《中国福利彩票双色球游戏规则》（中国福彩网 2026-01-29 发布，
自第 2026014 期起执行）：

| 奖级 | 中奖条件 | 奖金 |
|------|----------|------|
| 一等奖 | 6 红 + 1 蓝 | 浮动（待官方核定） |
| 二等奖 | 6 红 + 0 蓝 | 浮动（待官方核定） |
| 三等奖 | 5 红 + 1 蓝 | 固定 3000 元 |
| 四等奖 | 5 红 + 0 蓝，或 4 红 + 1 蓝 | 固定 200 元 |
| 五等奖 | 4 红 + 0 蓝，或 3 红 + 1 蓝 | 固定 10 元 |
| 六等奖 | 命中蓝球（红球不限） | 固定 5 元 |
| 福运奖 | 任意 3 红 + 0 蓝 | 固定 5 元 |

- 每注只兑付所中**最高奖级**，不兼中兼得（规则第二十九条），
  例如 3+1 只算五等奖，不叠加福运奖或六等奖。
- **福运奖启用条件**（规则第十八条）：当期奖池资金 ≥15 亿元时开始执行
  "特别规定"，执行后直至某期开奖后奖池跌破 3 亿元时停止。
  本程序为本地模拟器，**无法获知真实奖池**，因此固定按
  "未执行特别规定"处理，也不向用户提供开关；判定逻辑以
  `Judge(redHits, blueHit, specialActive)` 参数形式完整保留并可单测。
- 浮动奖金（一、二等奖）取决于当期奖池与销售额等官方数据，
  模拟器一律显示"**待官方核定**"，不编造金额。
- 若官方规则再调整，以官方公告为准；相关常量集中在 `prize.go` 便于核对。

### 3. 净收益统计（internal/lotto/bonus.go）

- 总成本 = 2 元 × 注数；固定奖金总额可精确求和；
- `NetDeterminable` = 固定奖金总额 − 总成本；
- 只要存在浮动奖金注，**最终净收益显示"无法准确计算（待官方核定）"**，
  否则给出确定的盈亏结论。

### 4. 终端界面（internal/tui）

- 仅使用标准 ANSI 转义序列与标准库（`text/tabwriter` 未用于含色单元格，
  对齐由自实现的显示宽度工具完成，CJK 字符按 2 列计）。
- 红球为亮红底号码芯片、蓝球为亮蓝底芯片；中奖信息绿色、警告黄色、
  提示青色；支持 `NO_COLOR` 环境变量，输出重定向到管道/文件时自动去色。
- 开奖动画使用 `\r` + 清行原地刷新；号码在动画开始前已全部取好，
  动画只是呈现层，可被 Ctrl+C 随时打断。

### 5. 信号与退出（main.go）

- 手动接管 `SIGINT`/`SIGTERM`：真实信号到来时取消长操作（动画）、
  打印提示、关闭随机源、以退出码 **130** 退出。
- stdin EOF（如 `Ctrl+D`）视为正常退出；非法输入给出黄色警告并重新提示。

## 常见问题

- **Fish Shell 下显示异常吗？** 不会。程序只输出标准 ANSI 转义序列，
  与 shell 无关；Fish / bash / zsh 均正常。
- **如何关闭颜色？** 设置 `NO_COLOR=1`，或将输出重定向到文件/管道。
- **为什么我的 3+0 没中福运奖？** 福运奖仅在官方"执行特别规定期间"
  （奖池 ≥15 亿元）有效，本地模拟器无法获知奖池，固定不启用。
